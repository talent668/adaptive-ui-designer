# Project-specific art direction

Choose a visible idea before assembling components. A working notebook, editorial journal, visual catalog or precise operations panel should follow the product's job rather than an industry template.

Capture a compact contract:

| Field | Decision |
| --- | --- |
| concept | What the interface should feel like and how that helps the task |
| signature | At least two visible traits: composition, type contrast, imagery or recurring domain motif |
| colorPlan | Canvas, reading surface, navigation, visual anchor, action and semantic pairs |
| typePlan | Display/body/technical roles, weight, measure and available family/fallback |
| layout | Main content, context, reading order and next action |
| imagery | Real sources or clearly labeled code-native illustration; none is valid |
| avoid | Concrete regressions to prevent |

Blue-white is the fallback, not a fixed layout. Explicit user colors and confirmed designs take precedence. A generic request for expression does not alone request a different hue. Use region scale, type, density and media to establish identity.

## Fit the scene

- **Workbench:** compact operational signals, meaningful trends, actionable exceptions and scannable records. Define period, scope and units. Avoid decorative charts and oversized metrics.
- **Reading/learning:** lead with continuation, content and a comfortable measure. Put context beside reading only when useful.
- **Brand/editorial:** lead with the work or story. Establish recognizable type and image treatment without sacrificing the next action.
- **Discovery/travel:** image-led composition can carry atmosphere. Keep crops intentional and text readable; local frost is different from making every surface transparent.
- **Technical tools:** show the actual object, state and next operation. Dense content can still have a strong identity.

## Offer meaningful alternatives

Keep representative content comparable. Change navigation, reading order or region proportions, paired with coordinated type or surface choices. Name a practical tradeoff. Do not pad the chooser with unprepared generic presets.

## Redesign from evidence

Inspect representative pages and states before prescribing changes. Separate hierarchy, shell, density, typography, color, components and task problems. Retain useful behavior while choosing polish, a regional redesign or structural recomposition according to the cause. A full audit or numerical score is useful only when requested or material to the decision.

Show a matched before/after or a concrete revised slice when possible. Do not fabricate a baseline for a new page or infer behavior from an image. A successful build is not an aesthetic verdict.
