# Guided first drafts — 2026-10-22

Package version: **v0.1.0**. Scope: default progressive disclosure, coordinated project directions, exact natural-language feedback handoff and reviewed agent responses. This record concerns the skill and its bundled preview, not a redesign of the earlier class-learning application.

## Delivered behavior

- A prepared project starts with its purpose, a coherent recommendation, up to two prepared alternatives and a rendered preview. Project settings and advanced details start closed; no beginner/expert label is shown. Existing detailed controls remain available without resetting the selection.
- Explicit project candidate sets take precedence over generic seeds. A single prepared candidate remains a single candidate. Advanced manual color/style changes remain available.
- Architecture, learning and operations examples use different content priorities, compositions, typography, material choices and domain artwork. They are synthetic examples; the agent must still inspect the actual project and prepare suitable directions.
- Ordinary-language feedback is interpreted by the current agent. The optional page note records the exact request and design baseline; it does not call a model. Pending requests block confirmation and generation until resolved or withdrawn.
- An independent working draft preserves changes made while feedback is pending. Reload restores that draft before checking an agent response. Stale, invalid, cross-project and non-style responses are rejected; missing or failed draft persistence prevents automatic application. A storage failure cannot guarantee recovery after the page closes and is reported as such.
