## Browser observations

The reviewer operated the real Chromium studio and inspected generated native pages:

- Choose mode disabled source until a matching explicit confirmation; later edits made prior artifacts stale while preserving their exact text. Prompt-only hid source actions and the controller rejected source generation; direct mode generated without an extra confirmation gate.
- Project context, composition, glass and icon choices survived saving/reloading. Language and appearance switches retained choices and literal custom project text. Prompt-language changes did not alter the website language or design contract.
- Copy placed the visible confirmed prompt on the clipboard. Generated `DESIGN-PROMPT.md` matched it exactly; `design.json` matched selected values, tokens and icons. Final contract contained 39 selected fields, 50 tokens per appearance, layout recipes, semantic SVG paths/treatment, project constraints, resource/license references and acceptance requirements.
- Baseline comparison preserved current controls, temporarily showed the earlier composition and blocked confirmation; returning/restoring worked as labeled.
- Independent typography controls changed title weight 600→700→500, 15px body leading 26.25→29.25→23.25px, and specimen measure 630→504→756px (70→56→84ch). Text reflow was visible and these selections survived reload and export.
- Flat cards had no shadow. Local gradient glass used 18px blur while dense tables kept a stable surface; the solid fallback removed blur and switching back restored it. Semantic duotone icons used 24px sizing, text color and 0.12 fill opacity in the checked configuration.
- Native React follow-state survived language/appearance changes. React and Vue detail dialogs opened, closed and returned focus to the initiating control.
- Same-content HTML examples were inspected at 1920×1080. A Vue split example also ran at 2560×1440 and 3840×2160 with no document horizontal overflow. DPR was 1; physical high-DPR panels, OS scaling and true browser zoom were not tested.

During live file updates the original preview origin mixed cached HTML/CSS with new JavaScript. The reviewer rejected that stale render as current evidence and repeated final checks on a fresh no-store preview origin. The final studio had no observed warn/error console entries. This was a preview-cache incident, not a claimed independent implementation defect.

## Visual review and limits

No unresolved P0–P2 issue was found in the inspected scope. The reviewer confirmed four real arrangements: sidebar workbench, main-content/context split, branded editorial lead, and compact records-first ledger. Navigation, module order, density and hierarchy differ; the same synthetic content remains available. Typography, action emphasis, semantic icons and material scope were coherent in the observed renders.

Tradeoffs remain: the split offers less single-screen density; the brand lead delays records and suits discovery more than frequent inventory operations; its bright night-mode brand block may not fit every user's low-luminance preference. These are selection considerations, not grounds for forcing one layout everywhere. Abstract portfolio/museum examples still need real project imagery and modules.

The implementer separately corrected export snapshot consistency, comparable module coverage, title-size binding, companion-color contrast and duotone icon color before final review. Do not attribute those self-found corrections to the independent reviewer.

Final Markdown/JSON/ZIP browser download-to-disk was not independently rerun. Clipboard, visible source and contract agreement were tested, and automated ZIP integrity checks passed; these are narrower claims. No new four-CLI model sessions, real customer integration, production APIs, full mobile QA or non-Chromium acceptance was performed. Historical CLI discovery/model evidence retains its earlier version and scope. The prompt captures a reproducible specification but includes no binary fonts and does not guarantee pixel-identical rendering in another environment.

Raw screenshots, interaction captures, logs and reviewed source hashes were retained with the task's independent-review artifacts.
